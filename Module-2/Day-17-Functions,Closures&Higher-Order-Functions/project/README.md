# Loyalty Points Module
## Project Overview
    A JavaScript module that implements a loyalty points system for a TeleBirr shop in Addis Ababa, Ethiopia. Built with closures for private state management and higher-order functions for flexible point calculation rules. The module demonstrates core JavaScript concepts including closures, higher-order functions, and pure functions.

## Features
    Private balance management using JavaScript closures
    Customizable earn rules via higher-order functions
    Safe redemption that prevents negative balances
    Multiple independent cards each with their own balance
    Pure functions for calculations, console output only at the edges
    Simple API with earn, redeem, and balance methods
