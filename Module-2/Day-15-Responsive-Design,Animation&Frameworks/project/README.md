# Habesha Eatery

A responsive static website for a restaurant in Addis Ababa, Ethiopia. Built with HTML and CSS only.

## Project Overview

This is the Week 1 project for the CodeOps Frontend module. It demonstrates responsive design principles, CSS Flexbox and Grid layouts, and clean semantic HTML. The site represents a real-world business with a marketing-focused design.

## Features

- Responsive layout that works from 360px mobile to 1280px desktop
- Mobile-first CSS approach with media queries
- Sticky navigation bar using Flexbox
- Hero section with fluid typography using clamp()
- About section with brand story
- Menu grid using CSS Grid with auto-fit and minmax
- Reservation form with validation styling
- Footer with address, contact, and hours
- Subtle hover transitions for interactive elements
- Respects prefers-reduced-motion for accessibility

## Sections

1. Sticky Navbar - logo left, navigation links right
2. Hero - welcome message and call-to-action button
3. About - restaurant story and history
4. Menu - responsive card grid displaying dishes
5. Reservation Form - labeled inputs with validation
6. Footer - Bole address, phone number, business hours
