# Buna Cafe - Telebirr Payment Shop

A simple, beginner-friendly shop page that accepts Telebirr payments. Perfect for small Ethiopian businesses!

## About the Shop

**Buna Cafe** is a cozy coffee shop in Bole, Addis Ababa that accepts mobile payments via Telebirr. This is a basic HTML/CSS demo showing how a small business can display products and accept payments.

## What is Telebirr?

Telebirr is Ethiopia's leading mobile payment service. Customers can pay by sending money to a business's registered Telebirr number.
